# 股票与 ETF 策略回测器设计

## 目标

构建一个仅在本机运行的股票与 ETF 回测 Web 应用，将两份现有 notebook 的策略和可调参数带入可重复使用的界面。首次打开即呈现 VIX 定投策略，使用 QQQ 和 notebook 风格的默认参数，可直接运行；用户可以追加策略、调整任意参数，并选择运行一个或多个策略。首版实现利率与历史 PE 信号。界面默认日文，并可切换为中文。

本应用用于历史模拟，不连接券商、不下真实订单，也不提供投资建议。

- 默认只配置并运行首屏 VIX 策略。用户可手动添加第二份 notebook 中的策略；策略条目可启用/停用，运行范围可为单条或全部已启用策略。
- 两份 notebook 中的策略、参数、开关、输出选择和网格搜索范围都纳入首版。原 notebook 中的利率与 PE 配置当前未参与计算；本应用必须实现实际信号逻辑。

## 方案与边界

采用本地 FastAPI 服务与 React/TypeScript 前端。前端负责策略配置、验证反馈、运行状态和结果呈现；FastAPI 负责请求校验、数据加载编排、策略运行和结果序列化。独立的数据适配器负责价格、VIX、利率、SEC 公司财务事实及 SEC ETF 持仓。回测内核只依赖规范化后的日频行情、财务/持仓时间序列和显式策略配置，不直接调用供应商接口。绩效分析与图表数据由策略执行结果推导，避免策略模块承担展示职责。

主要边界：

- **配置与校验**：共享回测范围、标的、月度注资等设置；每个策略实例拥有自己的信号、交易规则和参数。信号参数只影响引用它的策略。
- **数据适配**：供应商字段转换、交易日期对齐、单位归一、缓存和数据可用性诊断。原始响应不得泄漏进策略内核。
- **策略执行**：每条策略用同一回测合约运行：输入经过验证的配置及时间对齐的数据，输出每日资产序列、交易记录和状态。策略互相隔离，单条失败不抹掉其他成功结果。
- **绩效与结果**：计算统一的指标、基准、数据来源/截至日期和错误/警告；前端只呈现这些结构化结果。

运行链路为：编辑共享设置与策略实例 → 校验启用策略所需参数/数据 → 通过适配器取数和规范化 → 独立运行每条策略与基准 → 计算指标和状态 → 展示并允许 CSV 导出。数据缓存仅用于减少重复下载；缓存键至少区分供应商、代码、频率和日期范围，并向用户展示数据更新时间。

## 首屏与策略配置

### 默认 VIX 定投策略

首次打开时预置且启用一条 VIX 定投策略，不要求用户先手动添加信号。采用 notebook 的交易含义和接近 notebook 的默认值：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 标的代码 | `QQQ` | 可修改为股票或 ETF |
| 回测起始日 | `2020-01-01` | 可修改 |
| 回测结束日 | 最近一个有完整行情的交易日 | 以可立即运行作为默认；可修改 |
| 月度注资金额 | `100` | 可修改 |
| 月度注资日 | `1` | 按当月所选日注资；若非交易日，顺延到当月下一个有行情的交易日；可修改 |
| VIX 开关 | 开 | 默认信号 |
| VIX 代码 | `^VIX` | 可修改 |
| VIX 买入阈值 | `25` | VIX 大于或等于阈值触发 |
| 每月最多信号买入次数 | `1` | 可修改 |
| 现金强制买入上限 | `1200` | 月末现金达到或超过此值时强制买入；可修改 |
| 卖出 | 关闭 | 默认无卖出 |

按月将注资加入策略现金；达到 VIX 条件时投入可用现金。月末安全阀独立生效，与 notebook 一样：若现金达到上限则强制投入。默认每月 1 日并在首个有效交易日注资，对应 notebook 的月初注资意图；实际界面按可调日期顺延，不保留 notebook 的 `day <= 7` 硬编码。初始策略结果同时与同金额月度定投、将计划总注资额在首个有效日一次性投入的基准比较。行情默认采用 notebook 选取的调整后收盘价字段；数据适配器必须让整个回测区间使用一致的价格口径。

界面应把这条策略及其参数作为首屏主体；其他策略经“添加策略”入口按需加入，用户可以删除/停用单条实例，并快速选择运行当前条目或全部启用条目。共享的标的、日期和资金设置不复制到每条策略；信号、止盈/卖出、固定比例定投等策略专有设置归属对应实例。所有 notebook 中的配置项均须有可编辑控件，且不会因切换策略而静默重置。

V1 首屏按已确认的简约布局呈现：页首为应用名称与日文/中文切换；其下是一行共享设置（代码、起止日期、月度注资）；主体左侧编辑当前策略，右侧列出启用策略并提供新增策略、运行当前选中策略和运行全部启用策略的入口；底部为绩效摘要、资产曲线、策略/基准比较表及交易记录入口。窄屏改为单列，策略清单和运行操作排在参数编辑区之后；不因响应式布局隐藏核心操作。

### 第二份 notebook 的策略库

来自 `/Users/ronny/workspace/Fin_app/FinRobot/tutorials_beginner/compare_strategies.ipynb` 的功能作为可手动添加的独立策略：

- 多条件择时定投：VIX、RSI、均线偏离、布林带、利率、PE 买入信号；AND/OR 逻辑；可选固定比例定投。
- MA 趋势跟随（买入与卖出）：价格高于均线时投入现金；低于均线时退出持仓。

- 网格搜索：枚举用户配置的参数取值范围，并返回完整搜索结果和最优组合。
- 定额月度定投。
- 一次性投入。

每个实例可启用/停用。标的、日期及预算为运行级共享设置；策略本身的参数独立。仅运行被选中且启用的实例；停用实例不会执行，也不会进入汇总。网格搜索范围不得硬编码；用户可编辑 VIX 阈值、RSI 阈值、安全阀金额、固定定投比例及从 notebook 参数扩展出的搜索维度/取值。

### 可调参数清单

首版应覆盖 notebook 当前配置中的所有用户输入，而不只覆盖信号阈值：标的、日期、月度注资日与金额、强制买入现金上限、策略模式/实例选择、条件 AND/OR、固定定投开关与比例；VIX 开关/代码/买入阈值；RSI 开关/周期/阈值；均线开关/周期/价格相对均线的百分比阈值；布林带开关/周期/标准差倍数；利率开关/代码/阈值；PE 开关/阈值/ETF 持仓覆盖率门槛；卖出总开关、两级 VIX 卖出阈值与比例、RSI 卖出开关/阈值/比例、布林带卖出开关/比例；输出买入记录、绘图开关；网格搜索各维度和取值。无意义或不合法取值须在运行前指出并定位到具体控件。

## 信号语义与无前视偏差

- VIX 买入：`VIX >= 阈值`。
- RSI 买入：`RSI <= 阈值`；RSI 周期使用配置值。
- 均线择时买入：`(价格 - MA) / MA * 100 <= 偏离阈值`。趋势策略 2/3 使用 `价格 > MA` 作为持仓条件/买入条件。
- 布林带买入：`价格 <= 下轨`。原 notebook 的布林卖出为价格达到上轨且 VIX 低于 20；常数 20 也应显式成为可调参数，不可隐藏硬编码。
- 利率买入门槛：标准化后的利率 `<= 利率阈值`。默认代码为 `^TNX`，界面阈值用百分比显示，适配器按供应商字段约定转换单位后才与阈值比较。
- 个股 PE：在每个回测日期，以当日价格除以该日期前已公开的最新 TTM diluted EPS。若能取得最近四个独立季度 EPS，则相加作为 TTM；如果申报只提供年初至今累计值，则先按申报期差分还原单季值。最近四个季度不足时，退回该日期前最近已公开的年度 EPS；两者都不可得则 PE 不可用。拆股调整到与当日价格相同的每股基准。每项事实按 SEC 实际公开可用日（而非报告期结束日）参与计算，禁止用之后披露的数据填补过去。
- ETF PE：以该日期前已公开的 ETF 持仓快照和可匹配成分股财务事实计算。令 `w_i` 为股票成分 i 占全部股票持仓市值的权重，`EPS_i` 为 point-in-time TTM diluted EPS，`P_i` 为同日价格；ETF 盈利收益率为 `sum(w_i * EPS_i / P_i)`，ETF 等价 PE 为其倒数。亏损公司的负盈利贡献保留在求和中。若具备有效财务/价格的持仓市值覆盖低于股票持仓市值的默认 `80%`，或聚合盈利非正，则该日期 PE 不可用。覆盖率阈值可调整。
- PE 买入门槛：`PE <= PE 阈值`。PE 及利率首次真正进入多条件组合；启用信号集合按策略设定的 AND/OR 组合。AND 模式下所有已启用信号都必须有有效数据并通过；OR 模式下逐日评估可用信号，但若整段期间没有任何有效数据，需要显式失败而不能静默地不触发。
- 滚动指标只使用当日及此前数据。为形成 RSI、均线、布林带等指标，可向行情适配器请求回测开始日前所需的预热区间，但结果和交易统计只覆盖用户选定区间。

## 数据源与缺失处理

- 行情、VIX、利率优先从 Yahoo Finance/yfinance 获取，沿用 notebook 的免密钥使用方式。它属于外部免费数据源，不能承诺服务可用性、完整历史或稳定限流；供应商接口应可替换。
- 个股财务事实优先来自 SEC EDGAR CompanyFacts/XBRL。ETF 历史持仓优先来自 SEC N-PORT 公开申报数据。SEC 数据只在公开申报可用之后参与当日及以后的估值；申报频率、覆盖和匹配质量会导致估值延迟或缺口。
- 价格、指标、持仓和财务事实每一序列都保留来源与可用日期。禁止将未来信息回填进过去；对 VIX/利率或价格的缺口不默认无限前向填充。允许的日期对齐规则应有上限，并在结果中披露。
- 运行前按策略依赖校验数据。标的价格缺失或日期范围不足时，相关策略报不可运行；单个信号缺失时按已确认的 AND/OR 规则判断能否运行。PE 数据不可用时，依赖 PE 的策略显示未运行及具体原因，包括标的无 SEC/持仓覆盖、持仓覆盖低于门槛、财务数据缺失或聚合盈利非正。
- 每条策略有独立状态：排队、运行中、完成、完成但带警告、未运行/失败。单条策略失败不丢弃其他有效结果；总视图须区分“策略计算失败”和“源数据不足”，不可把两者合成空结果或展示为零收益。
- 供应商错误、限流、无行情、无财务事实、无公开 ETF 持仓、日期范围无重叠、输入越界均给出简明、可操作的日文/中文说明。记录可供诊断的日志，但不要求首版引入远程监控服务。

## 结果体验

- 首屏运行后展示策略与月度定投、一次性投入基准的比较表，至少包括期末资产、总投入、总回报/投入本金比例、年化回报和最大回撤，并能看到相对月度定投的期末超额。
- 定投策略的年化回报按真实注资日期的现金流计算为资金加权年化回报（XIRR）；若现金流没有可解的有效结果则显示不可用，不沿用 notebook 将期末值除以累计投入后当作 CAGR 的简化公式。最大回撤从扣除外部注资影响的单位净值序列计算，避免持续注资掩盖投资损失。总回报与最大回撤的定义在 UI/导出中保持一致。
- 资产曲线同时支持策略与基准显隐、单条/多条策略比较，并标记买入和卖出交易；价格与 VIX 可作为辅助图表。回撤通过独立序列/面板展示，避免和资产曲线混为一条指标。
- 策略表清晰显示每条状态、是否已启用、数据范围/截至日期和缺失原因。网格搜索展示参数组合、目标值排序和二维热图；完整结果可下载 CSV。交易记录输出开关影响交易明细视图/导出，不应影响策略执行。
- 默认日文，提供可见的日文/中文语言切换；语言切换不改变配置或回测结果。日期、百分比、金额、代码和来源均以一致格式和单位呈现。

## 测试要求

- 纯策略单元测试：VIX/RSI/均线/布林/利率/PE 阈值边界、AND/OR、现金注入、月度次数、安全阀、固定比例定投、两级卖出和趋势策略状态转换。
- 时间与数据测试：交易日注资、指标预热、价格序列对齐、利率单位归一、财报披露日/SEC 申报可用日的 point-in-time 防前视、ETF PE 加权公式/亏损持仓/覆盖率边界/非正聚合盈利。
- 合约与集成测试：API 输入验证、未知代码/缺失行情、策略部分成功/部分失败、PE 不可用时其他策略仍成功、结果和 CSV 的字段/单位一致。
- 前端测试：添加/停用/移除策略、全部/单条运行、参数编辑校验、状态和缺失原因显示、日中切换、结果曲线显隐及 CSV 导出操作。
- 回测示例使用固定的本地行情与 SEC fixture；正常测试不依赖 live Yahoo/SEC 网络。提供可选的手动 smoke check 来检查 live 适配器，且与确定性测试分开。

## 不在首版范围

- 券商接入、真实订单、账户同步、自动化交易、用户账户/云端同步。
- 对所有股票/ETF 保证可用历史 PE；任何商业数据订阅作为必需条件。
- 期权、空头、杠杆、税费/滑点的完整模拟、投资组合多标的资产配置。
- 用户认证、部署到公网、多用户并发管理。

## 验收标准

1. 在干净的工作目录启动本机应用后，首屏显示启用的 VIX 定投策略，默认 QQQ、`^VIX >= 25`、月度注资 `$100`、现金安全阀 `$1200`、无卖出；默认日期到最近完整行情日。
2. 不填写额外策略时，可仅运行该 VIX 策略并看到同 notebook 方向的交易记录、资产序列和两种基准比较。
3. 能从策略库追加上述每类策略、调整该类 notebook 中的所有输入参数、独立启停，并选择单条或所有已启用策略运行。
4. 个股 PE、ETF PE、利率信号都有明确且可测试的计算口径；缺失 PE 不会误用未来数据或阻止不依赖 PE 的策略完成。
5. 各策略结果互相隔离、缺失/失败原因可见，曲线、交易记录、指标和 CSV 保持一致。
6. 日文为初始语言，用户可切换中文且不丢失当前配置。
