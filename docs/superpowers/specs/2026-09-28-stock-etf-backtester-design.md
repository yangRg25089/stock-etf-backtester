# 股票与 ETF 策略回测器设计

## 目标

构建一个股票与 ETF 回测 Web 应用，可在本机运行，也可由用户显式部署为带共享密码保护的单实例 Render Web Service。应用将两份现有 notebook 的策略和可调参数带入可重复使用的界面。首次打开即呈现波动率信号定投策略，使用 QQQ 和 notebook 风格的默认参数，可直接运行；用户可以追加策略、调整参数，播放运行全部已添加策略及自动基准。首版实现利率与历史 PE 信号。界面默认日文，并可切换为中文。

本应用用于历史模拟，不连接券商、不下真实订单，也不提供投资建议。

本文件是交易规则、数据口径、错误处理和验收条件的唯一依据。[复用与组织规范](../../design/reuse-and-organization.md)集中定义策略目录、参数所有权、界面组件、模块接口和工作顺序；[V1 画面设计源](../../design/backtest-ui.html)呈现这些规则。[审查指摘对照](../../design/review-resolutions.md)仅记录每项问题的归属，不新增规则。重复出现的同类功能只能引用同一条定义，不另建并行规则。

主要边界：

- **配置与校验**：共享回测范围、标的、月度注资和数据有效期；每个策略实例拥有自己的交易规则与信号参数。注册表是类型、默认值、单位、范围、适用策略和字段分组的单一来源。
- **数据适配**：供应商字段转换、交易日期对齐、单位归一、缓存和数据可用性诊断。原始响应不得泄漏进策略内核。
- **策略执行**：每条策略用同一注资日历、信号三态、成交顺序和资金账本；输入验证后的配置及时间对齐的数据，输出每日完整总资产与交易。单条失败不抹掉其他成功结果。
- **绩效与结果**：搜索候选、普通策略和基准调用相同指标模块；状态、错误码、数据来源和导出由不可变运行快照衍生，前端只呈现结构化结果。

运行链路为：编辑共享设置与策略实例 → 确定当前实例或全部实例 → 冻结所选实例的配置 → 对每个所选实例独立校验参数与依赖 → 获取规范化数据快照 → 独立运行各策略与共用基准 → 计算指标/状态 → 显示并导出同一快照。只运行当前实例时，未选实例的错误不得阻断它；多实例运行时，某一实例的错误不得阻断其他实例。数据缓存仅用于减少重复下载；缓存键区分供应商、代码、频率、日期、数据版本和价格口径，并使用有界 LRU 与显式刷新入口；结果展示数据截至日期。

## 统一日历、账本与成交

共享注资日历生成器供全部策略、基准及搜索候选复用。用户起止日期含边界；选定结束日冻结为用户选择值，有效行情窗口截至已提供的完整报价日，单日缺口清洗不显示延迟警告。注资日为 1..31，短月截到月末日历日；若该日不是交易日，取同月其后的首个交易日，若没有则取同月最后交易日。只保留有效回测区间内的计划，月中开始不补缴此前应注资额，月中结束不预缴未来额。一次性投入的本金等于同一注资日历中有效计划金额的总和，在首个回测交易日投入；它有提前投入未来计划金额的资金时点假设。区间无有效注资时提示调整计划，不能算出伪造的收益率。

每条策略使用同一账本：`总资产 = 现金 + 择时持仓价值 + 计划持仓价值`。择时策略注资先进入现金，只有信号或安全阀成交才计入实际买付额；自动 DCA/一次投入基准的计划仓仍使用共享排程和账本。卖出只动择时持仓。无论现金是否为 0，每个交易日都估值并评估可能的卖出。

共享成交假设由注册表提供：每笔佣金（报价币种）、滑点和买卖价差（百分数）、允许碎股，默认0/0/0/true。滑点与半价差之和必须小于100%。所有策略、计划买入、安全阀、基准和搜索候选复用同一纯成交函数；买价为模拟基准价×(1+滑点+半价差)，卖价为基准价×(1−滑点−半价差)。买入预算先扣佣金，整股买卖向下取整、余款留现金；不足一股、预算不足佣金或卖出净回款不正时不成交、不收费，也不占信号买入次数或抑制其他真实买入。

`cashAmount`为实际现金变化的正数：买入含佣金、卖出扣佣金；`grossAmount`保存数量×成交价的成交额。每笔保存TradingCosts的佣金、滑点损耗、半价差损耗及合计，日次保存当日费用、汇总读取同一成交费用。资金来源追踪消费实际现金支出，再买不重复计本金。费用也计入NAV：已有持仓先按当日基准价估值，外部注资按费用前NAV发行单位，再用费用后净资产估值；不能把当日费用当成外部现金流抹掉。所有主KPI、XIRR、净值回撤和年/月收益使用净资产；换手率使用gross成交额。成本合计不冒充无费用情况下另一次回测的资产差额。

简化资本利得税是共享成交设置 `execution.capitalGainsTaxEnabled`，默认关闭；开启时每次卖出按 `max(扣除卖出佣金后的收入 − 已售份额的平均成本, 0) × 20%` 即时从回款扣税。平均持仓成本含买入佣金，按择时持仓池独立追踪；部分卖出按份额分配成本，收益和回收本金再买更新成本而不重复计外部本金。亏损不退税、不抵扣其他成交；未卖持仓不扣，期末不强制平仓。税额保存至同一 TradingCosts、交易、每日及汇总结果，包含在总费用与净资产绩效中。所有策略、基准、候选和连续 Walk-forward 共享此计算并衔接剩余成本。该简化模型不模拟任何地区的完整税法。

策略模拟价格沿用 notebook 的调整后收盘价；持仓份额和成交价为该复权口径下的模拟值，不重复派发股息。PE 使用独立估值价格。依赖当天收盘形成的信号在下一交易日收盘成交；回测最后一日形成而不能在区间内成交的信号记录为未执行。这个因果顺序有意不同于 notebook 的同日收盘信号/同日收盘成交，因此不承诺与源 notebook 逐数字相同。

每日顺序统一为：注资 → 计划型买入（DCA/首次一次投入）→ 前日信号卖出 → 前日信号买入 → 交易所实际月末安全阀 → 总资产估值 → 当日收盘信号。卖出执行日抑制同日择时买入和安全阀回补，DCA 基准计划照常执行。安全阀只在实际交易所月末检查，不能把回测在月中截断的最后一日当月末。

月度信号买入次数以成交的年月计；DCA 基准与安全阀不占次数。两级 VIX 卖出按实际较低阈值优先，使用该阈值对应的比例；阈值可以反向编辑，不能按字段编号判定高低。相同阈值保留既有第二档优先的行为。多个卖出条件同日命中时取最大卖出比例，不相加。买入开关与卖出开关独立：即使 RSI/VIX 买入关闭，启用的相应卖出规则仍需要该序列。布林卖出的 VIX 上限从原硬编码 20 改为可调字段。

## 信号与统一缺失规则

| 条件 | 有效数据上的判断 |
| --- | --- |
| VIX 买入 | `vix >= threshold` |
| RSI 买入/卖出 | `rsi <= buyThreshold` / `rsi >= sellThreshold` |
| 均线偏离买入 | `(simulationPrice - MA) / MA * 100 <= deviationPct` |
| MA 趋势 | `simulationPrice > MA` 买入；买卖变体在 `simulationPrice <= MA` 卖出 |
| 布林买入/卖出 | `simulationPrice <= lower` / `simulationPrice >= upper && vix < sellVixCeiling` |
| 利率买入 | 归一成百分数值后 `ratePct <= thresholdPct`；默认阈值 `2.5` |
| PE 买入 | 有效正 PE 且 `pe <= threshold`；默认阈值 `25` |

RSI 使用 notebook 的滚动算术均值，MA 使用简单均值，布林带使用样本标准差；指标方法版本化，不在同类策略中复制不同实现。技术指标只读当日及以前的行情，可请求回测区间之前的预热行情；预热期不注资、不计绩效。

每个被启用的买入或卖出依赖在每个需要评估的交易日输出 `true / false / unavailable` 与结构化原因。统一采用严格依赖：任何必需信号在该日不可用，整条依赖它的策略为 `unavailable`，不输出不完整收益；其他策略继续。AND/OR 只组合有效布尔信号，OR 不允许静默跳过缺失的 PE 或其他启用信号。禁用信号不形成依赖；空买入信号集合为 false，注资/安全阀规则仍可运行。运行前诊断与结果诊断使用同一状态码与数据依赖解析，不为 PE 另设例外。

## 数据源与缺失处理

阶段 32 逐策略审计确认默认 Yahoo `^TNX` 报价为百分数收益率，目录显式配置 `rate.sourceUnit=percent_point`；这是默认来源和单位的一组配置，不是适配器根据代码推断倍率。单位选项仍可编辑，`auto` 缺少供应商单位时返回一个可操作诊断，不能每天重复堆叠错误，不能猜测或把未知单位当成有效信号。[Yahoo 债券报价](https://finance.yahoo.com/markets/bonds/)与[联储 DGS10 百分数单位说明](https://fred.stlouisfed.org/series/DGS10)用于核对默认报价量级，二者不是逐报价相同的序列。

规范化领域边界要求行情日期严格递增且唯一；行情 `observedAt` 及宏观 `observedAt/publishedAt`（存在时）必须带有效时区，不补猜时区。数据组合只接受相同回测窗口、目标交易日、频率与规范化版本的结果，宏观对齐日必须具有对应的实际行情；具体上下文/缓存契约见复用规范。已知坏响应返回数据不可用，供应商调用异常返回提供方诊断，本地程序错误返回计算失败并记录安全元数据，不泄露异常原文。

行情、VIX、利率优先用 Yahoo Finance/yfinance；公司财务事实优先用 SEC CompanyFacts/XBRL；ETF 历史持仓优先用 SEC N-PORT 公开申报。供应商适配器向回测模块提供统一的报价币种、交易所日历、`simulationPrice`（模拟总回报价）、`valuationPrice`（不含分红调整且与 EPS 拆股基准一致的估值价）、数据时间戳、来源及数据指纹。两种价格无法可靠区分时，依赖 PE 的策略不可用，不擅自代用。利率统一为百分数值；不能只凭 `^TNX` 代码猜测转换倍数，无法确认来源单位时要求明确设置或报单位错误。Yahoo 适配器依据 [yfinance PyPI 发布页](https://pypi.org/project/yfinance/)（当前验证版本 1.7.0）及其 [`Ticker.history` 实现](https://github.com/ranaroussi/yfinance/blob/1.7.0/yfinance/scrapers/history.py)、[quote 实现](https://github.com/ranaroussi/yfinance/blob/1.7.0/yfinance/scrapers/quote.py)：显式关闭自动/回溯调整，按 inclusive `start`、exclusive `end` 请求，只有明确的调整收盘价与收盘价时分别映射为两种价格口径；币种必须来自明确行情元数据，字段缺失或冲突均不可用，不假设 USD。

行情价格不前向填充或插值。运行编排可把每段仅缺少一个交易日的行情缺口从共享交易日历中移除；所有策略、基准和搜索候选都跳过该日，不合成价格，也不因此显示警告。连续缺失两个或更多交易日仍按必需行情不可用处理。动态结束日期直接以行情快照中的最后有效收盘日为准，之后尚未发布的日历交易日从本次运行日历中剔除，不显示来源延迟警告。VIX/利率可使用当时已经发布且不晚于目标交易日历 3 个交易日的最近观测，该上限是可调共享数据设置。宏观规范化保留源观察日、观察时间、可核实的发布时间和来源单位；对齐后的交易日另存，不覆盖任何源日期。由于交易日历不提供每个 session 的收盘时点，无法核验时同一日历日期的宏观观测一律从下一交易日开始使用，不根据供应商时间戳推断同日收盘前可用。as-of 选择不得早于源数据可用时间，陈旧度按交易所 session 计数，超过设置的观察不生成对齐值。财务与持仓按公开时间进行 as-of 查询，分别默认不晚于财务报告期结束后 550 个日历日、持仓快照后 180 个日历日，两个有效期亦可调并进入运行快照。过期、币种不一致、数据缺失或交易区间无重叠都通过同一诊断机制处理。

供应商明确提供首个交易时间且与实际行情不矛盾时，可将上市前起始日调整到其可用首日；不把未知的头部缺口猜成上市日期。原始 `RunSnapshot.config` 在受理时冻结，worker 加载数据后将原/实际日期及原因绑定到不可变 `RunDataContext`，所有策略、基准及搜索共用其中的实际区间；注资按调整后区间重新排程，不补缴上市前或首个不完整月份。首日 VIX 等前日观测仍保留上市前的交易所日历上下文，不能因标的尚未上市而删除已有指数数据。完成后的完整响应仅同步仍匹配请求的草稿日期，并简短告知；未完成作业重连同样遵守匹配检查，其他已编辑请求不被覆盖。旧无 dataContext 的文件沿用其已保存的区间。

已知上市边界截断指标预热时，使用真实收盘样本将共享起点解析到所选策略能够完整预热的首日，记录 `indicator_warmup`；不缩短周期或生成上市前行情。某策略的完整周期超出整个可用区间时，仅该策略不可用，不阻断其他可恢复策略和基准，所有成功结果仍使用同一共享窗口。整段区间均在上市前时，默认保留原结束日，准确给出可用首日及最近完整行情日的调整入口；点击只修改仍匹配该请求的草稿，下一次播放才计算。该结束日期处理为未收到可选偏好回复时的保守默认，不能当作用户明确批准自动延长区间。无有效注资和非日期供应商错误保留原诊断，不通过改变投入计划或隐去缺失获取成功。

每项 SEC 事实保留报告期、申报/更正标识、实际公开可用时间及来源版本。只在已公开后参与信号，后续更正不回填此前日期。对于只有公开日期、无法确认具体日内时间的记录，从下一交易日才视为可用；连公开日期也无法核实则不可用。基金持仓不能用今天的组合回填历史。[SEC CompanyFacts 接口](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)和[SEC N-PORT 公开数据范围](https://www.sec.gov/data-research/sec-markets-data/form-n-port-data-sets)是首版免费来源，部分标的与日期缺少可用 PE 是预期限制。

### 个股 PE

在交易日 t，选择当时已公开的最近合格十二个月 diluted EPS：可用时用最近四个已披露、期间连续且不重叠的独立季度 EPS 合计，标明它是 `quarter_sum_estimate`；或使用最近已公开的完整年度 EPS，标明 `annual_report`。依据实际报告期结束日选择最新的合格口径，若结束日相同则优先年度报告。年度回退值保留年度期间和数据龄期，不假称为最新季度 TTM。不能直接相减累计 YTD EPS 还原季度，因为各期间使用的加权平均股数不同，季度 EPS 之和也不必等于全年 EPS。[SEC 申报中的说明](https://www.sec.gov/Archives/edgar/data/1174850/000117485025000023/R11.htm)。

EPS 与 `valuationPrice` 必须为同一股票类别、币种与拆股后的每股基准。若 EPS <= 0、基准不匹配、无合格口径或超有效期，则 PE 不可用；否则 `PE = valuationPrice / EPS`。负 PE 不得通过 `PE <= 25`。

### ETF 持仓 PE 估算

动态标的中，仅有可核对历史直接股票持仓的普通实物多头股票 ETF 可计算“股票持仓 PE 估算”；债券、杠杆/反向、合成及需要穿透其他基金的 ETF 不推算。依赖能力检查及公开申报数据，而不是固定允许代码名单。估算标明股票部分占基金比例、持仓快照日期、覆盖率、EPS 口径，不标为整个 ETF 原生公布的 PE。

令 `w_i` 为历史快照中成分 i 占全部直接股票持仓市值的权重，`K` 为身份、财务与价格均匹配的成分集合，`C = sum(w_i, i in K)` 为有效覆盖率。要求 `C >= minCoverage`，默认 0.80，可调；未知成分的盈利不当作 0，而对覆盖部分重归一。`earningsYield = sum((w_i / C) * EPS_i / valuationPrice_i, i in K)`；它保留有效亏损公司的负盈利贡献。若收益率 <= 0，则估算 PE 不可用；否则 `estimatedPE = 1 / earningsYield`。持仓权重取公开快照的已披露权重并维持到下一份可用快照，属于明示估算。

个股买入 PE 需要正 EPS；ETF 聚合却必须包含有效负 EPS，因此复用的是有符号每股盈利收益率计算，不可把“个股 PE 不可用”的结果直接当作 ETF 成分覆盖缺失。

### 策略级错误与状态

领域 `RunResult` 的空策略集合仅允许 `queued`；有子结果时始终由子结果聚合状态。无作业仍由页面 `empty` 表达，不允许空集合声明执行中或完成。

每条运行的策略独立返回 `queued | loading | running | completed | completed_with_warning | unavailable | failed`，状态和诊断码在前后端、列表、结果和 CSV 共用。参数错误、供应商请求错误、所需数据不可得和策略计算异常明确区分；局部参数失败的实例仍冻结原提交条件树，保留完整复现输入；数据不可用不能显示为零收益。任一所需 PE/VIX/RSI/均线/布林/利率缺失，只影响依赖该数据的策略；其余成功结果保留。源数据质量提醒与估值方法标签可使已完成结果带警告，但不能用警告绕过必需数据验证。

- 技术指标图使用运行时统一指标缓存保存的实际值：MA 标明周期，布林标明周期/标准差倍数及中/上下轨，RSI 标明周期。价格单位的 MA/布林与价格使用同一首个有效收盘价基准；RSI、VIX、回撤维持自然单位，紧凑联动，不分别重设每条指标起点。预热/缺失样本保持 null，曲线断开而不插值，不读取当前草稿或额外下载/计算。普通策略与搜索候选均保存这些值，旧结果没有指标时不臆造。交易信号、账本和收益算法不变。

- 全部策略、基准及搜索候选从完整总资产账本和统一指标模块计算：`totalContributed = 实际有效注资之和（包括尚未买入的现金）`、`actualInvested = 注资首次用于买入的累计本金（回收资金及收益优先再投资，不重复累计）`、`endingEquity = 期末总资产`、`netProfit = endingEquity - totalContributed`、`returnOnContributions = endingEquity / totalContributed - 1`、`capitalMultiple = endingEquity / totalContributed`。比较表显示已投入本金，不显示与一次投入基准重复的注入本金；另显示保存快照内的资本利得税支出。开启简化税制后，每次卖出按卖出手续费后的净收益扣 20%，亏损不抵扣盈利，未卖持仓不计税；默认关闭。税金作为交易费用从卖出所得及现金余额中扣除，并同步进入指标、比较、交易成本、CSV 和报告。`investmentBasis` 区分新本金口径和旧成交累计，旧值不冒充新值。收益率、XIRR 和回撤口径不改。百分比回报与资产倍数分开命名，不能把 `endingEquity / totalContributed` 标为盈利率。
- 年化回报对策略和两种基准均用各自实际外部现金流与终值算 XIRR，年化日数按实际天数/365：月度策略/DCA 按有效注资日记流入，一次性投入按首日全部本金记流入，不能把提前投入又记为后续月度流入。无唯一有效解时只将 XIRR 标为不可用并附原因，不伪造年化值。最大回撤从扣除外部注资影响的单位净值序列计算；每日 drawdown 用不大于零的比例表示，汇总 `maximumDrawdown` 存其正向绝对值。贡献在计划买入日收盘按当日外部注资前的单位净值发行份额，避免将收盘成交前的新资金误记为当日收益。所有中间计算保留精度，显示时才舍入。
- 新增PerformanceAnalysis独立于XIRR，基于现金流调整后的单位净值：从首次实际注资起，以发行净值1计首日收益，终值按实际日数/365年化；日收益样本波动率及Sharpe/Sortino按252交易日年化。Sharpe用超额日收益均值/样本标准差（[Sharpe原文](https://web.stanford.edu/~wfsharpe/art/sr/sr.htm)）；Sortino下行偏差按全部观察的负超额收益均方根（[PerformanceAnalytics实现](https://github.com/braverock/PerformanceAnalytics/blob/master/R/DownsideDeviation.R)）。Calmar为NAV年化收益/最大回撤。分析无风险年利率默认0%，由唯一注册表提供，日利率为(1+年利率)^(1/252)-1；此参数不使现金实际计息。缺历史、零波动、无下行、无回撤或零NAV后不可定义收益，以null和原因表示，不生成无穷值或额外失败。
- 最长回撤期为峰日至恢复日（未恢复截止末日）的最大日历日数；恢复期为最深回撤谷底至恢复日，未恢复为null。买卖数按实际成交笔数；gross换手率为买卖成交额之和/注资后平均总资产，现金占比为正总资产日的现金比例均值。UI与CSV读取保存分析值，旧结果缺分析值不在前端补算。
- 年/月表现是保存单位净值的期间收益，不对部分年份/月再次年化：该期末NAV/前一保存期末NAV−1，最初以发行净值1为基准。收盘价同口径使用期末/前一保存期末价格−1，最初以运行首个保存价格为基准。每期保存实际观察日期；无注资、缺NAV或前期净值为零保留null及原因，不假定零收益或跳过缺值。一个可排序热力表依次展示1–12月和年度总收益列；年度收益取保存的年度指标和同次运行基准，不从月收益相加。年度列以边框高亮，单元格和选中月份详情最多显示两位百分数小数，完整精度保留在悬停title、快照与CSV；正负/缺值有文本语义。

## 验收标准

1. 首屏预置波动率指数定投策略，默认 QQQ、`^VIX >= 25`、每月 100（QQQ 为 USD）、现金安全阀 1200、无卖出，默认结束日为本机今天；界面同时显示当前 VIX 参数摘要，无需添加其他策略即可运行。
2. 统一目录保留七类，界面可添加五类预设且每种可添加预设最多五个实例、用户策略总数最多十个；月度 DCA/一次投入为必选自动基准，不作为用户可添加策略。实例复制后参数独立，首个名称无序号，重复项追加序号；删除不改变其他实例身份。策略限制来自 catalog 并由后端校验，菜单、reducer 与文件读取遵循同一限制。同一类型参数在普通策略、搜索、校验、导出只维护一份定义。
3. 唯一运行入口执行全部实例，不显示范围选择；后端保留 active/all_enabled 契约；弹窗缓冲、草稿、作业、结果聚焦和曲线显隐分别管理，不互相隐式改变。旧运行快照在表单改变后仍有正确保存标签与导出，右侧内容与诊断不受草稿校验影响。
4. 统一注资日历、成交时序、固定/择时账户与指标模块保证普通策略、基准、搜索候选使用相同口径；特别验证无信号时实际买付额、基准计划和次日信号成交。
5. 利率和 PE 真实参与信号；个股、ETF 计算及免费数据不可用原因透明。任一启用必需信号缺失，依赖它的策略不可用，其他策略继续，不能把缺失转成 false 或零收益。
6. 结果表、资产/回撤曲线、收盘价走势折线、VIX 观察曲线、交易明细和 CSV 与当前聚焦的不可变结果一致；标的价格与累计本金收益始终在核心比较图中，价格起点 100、本金收益为资产/累计本金×100，可选回撤/VIX 可在底部紧凑指标区联动查看，任一图表的时间窗口操作同步到所有图表；图表有网格、日期/数值轴和原币种/百分比说明，零交易成功、无数据、部分成功和运行失败可区分。
7. 首次打开按浏览器语言偏好选择日文、中文或英语（未识别语言使用英语）；手动选择保存至本机 localStorage 并在后续打开时优先恢复。320、768、1024px 下同类控件保持统一单位、尺寸、标签和可用操作。
8. 策略比较、交易明细、年度/月度绩效、回撤区段、搜索候选和网格参数结果表均可按列排序；数字按精确十进制比较，空值置后，并列稳定。月度涨跌色首次按语言显示（日/英绿涨红跌，中文红涨绿跌），人工切换独立保存。
