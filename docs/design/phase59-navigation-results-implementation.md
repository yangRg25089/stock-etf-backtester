## 税金口径

按用户确认，税金只在每次卖出时针对该笔已实现盈利计算20%；未卖持仓不扣税。实现使用卖出收入扣除卖出费用后减去按比例分摊的持仓平均成本，平均成本包含买入费用；负收益不产生税金。回收现金再次买入时按新的持仓成本继续计算。固定fixture覆盖盈利、亏损、零交易和卖出后再买，普通运行与搜索/Walk-forward共用账本口径。税金默认为关闭，并由保存结果快照派生表格、CSV和报告字段。
