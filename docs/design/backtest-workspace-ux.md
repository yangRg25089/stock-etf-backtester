# 回测工作台 UI/UX 设计

## 状态与目标

本设计由用户于 2026-09-30 确认，并由 [`tasks/plan.md`](../../tasks/plan.md) 阶段 11 分步实现。用户追加的视口留白、左栏设置和结果层级优化由阶段 12（Task 39–42）补充实现；设置弹窗、固定侧栏开关、运行状态优先级和图表手势修复由阶段 13（Task 43–46）补充。只调整交互布局、内容层级与可访问性，不改变回测算法、数据来源、API 契约、保存快照或 CSV 字段。

用户最新扁平化要求及实际页面审计已整理为 [当前方案](workbench-flattening-proposal.md)，对应阶段 14–17。Task 47–70 已完成，Task 70/55 的最终复审及交付已经验收。下文保留为阶段 11–13 的历史交付基线。当前规则：左右边界无边框开关；五类可选预设且同类型最多一个；两个必选自动基准；卡片悬停/键盘聚焦操作；顶栏只有播放/清空结果；dialog 编辑与保存结果隔离；策略比较集中全部指标并点击聚焦；价格与累计本金收益主图，下方联动指标采用自然单位和较小高度，分图采用相同完整尺寸。累计本金收益为总资产÷当日累计本金×100；单位净值继续用于原有回撤计算。共通摘要分行，买入组合使用 AND/OR 与信号卡片关系，布尔信号用独立 switch；图表十字线跨图同步保存日、左上读取原始金额/本金/指数和自然单位指标。下文的调宽/范围菜单/旧输入提醒/独立指标及单位净值展示仅为历史记录。

目标是让桌面用户在同一个工作区编辑输入、选择策略、运行并查看主要结果，减少横向空白和重复纵向滚动，同时保留日文默认、中文切换、窄屏可用及既有图表行为。

## 页面分区

### 固定顶区与运行条

- 应用顶栏保留产品名称和语言切换。
- 顶栏下的固定标题/ETF 信息区显示回测标题、标的、日期范围、月度投入摘要、运行范围、执行按钮和整体进度/状态。摘要可打开唯一的共享设置表单，不建立重复输入。
- 默认运行全部已启用策略；`runScope`、运行可用性、进度、服务重启后恢复和单策略局部失败行为保持原语义。执行使用醒目的图标按钮，屏幕阅读器名称和 tooltip 保留动作含义。
- 桌面应用顶栏和标题/ETF 信息区均固定在视口上方；滚动左侧详情或右侧结果时不会离开视野。新增控件可用键盘操作并有明确标签和焦点。
- 左侧栏开关是标题区内同一个常驻按钮；展开/收起只切换方向图标、可访问名称与 `aria-expanded`，按钮位置不变。

### 配置区

- 桌面宽屏使用可折叠/可调整宽度的左栏，初始宽约 350px、范围 320–420px；右侧由结果区占满剩余宽度。左右区各自填充固定标题/ETF 信息区下方的剩余视口高度。
- 左侧栏上半部的共享设置摘要和策略导航固定在工作区；空间不足时导航区自身滚动，使策略列表和添加目录入口仍可达。当前策略编辑器位于其下方独立的垂直滚动区。
- 共享设置默认显示当前标的、期间与投入计划摘要。点击齿轮图标打开原生模态对话框，完整编辑标的、日期区间/动态结束日期、投入金额和每月日期；表单继续复用 catalog、`ParameterField` 和校验管线。字段编辑即时更新当前草稿；“完成”或 Escape 关闭对话框。
- 对话框在宽屏使用清晰分组和两列字段，窄屏改为单列；内容区独立滚动，标题与“完成”操作保持可见。打开时背景不可交互，关闭后焦点回到触发按钮。对话框不挤压左侧策略导航，也不覆盖工作区形成无控制浮层。
- 纯操作按钮可用图标，但保留屏幕阅读器名称、焦点样式和悬停提示；策略及数据序列名称保留文字。
- 策略列表显示独立实例、参数摘要、启用和校验状态，并保留添加七类目录及删除功能。调整当前策略详情区时，列表不随之移动。
- 仅 `activeStrategyId` 对应的策略展开编辑。切换编辑对象不能改变启用状态、运行范围、`focusedResultId`、曲线显隐或已保存快照。
- 参数依 catalog 分组，按买入条件、资金分配、卖出条件和适用的高级参数组织；折叠只隐藏内容，不重置/覆盖配置。禁用条件保留摘要与原值。

### 结果区

- 显示当前正在查看的保存结果/策略/基准、状态、进度和诊断；草稿与保存快照不同时清楚说明图表仍对应旧输入。
- 全部完成且无诊断的运行默认收起重复的逐策略状态行；运行警告、失败、不可用或诊断存在时自动展开，整体状态与诊断保持可见。
- 结果区首卡为当前聚焦的保存策略指标；优先显示总投入本金、期末总资产、投入收益率、年化收益（XIRR）、最大回撤。实际投入、净利润、资本倍数、相对定投差值等现有指标可在完整指标页访问。
- 执行状态摘要位于结果区顶部、当前指标卡之前。成功无诊断时收紧为一行，运行 ID 和逐策略状态仍可展开；警告、失败、不可用与诊断保持完整且置顶。旧快照提示紧邻对应结果数值。
- 主图默认显示 QQQ 价格与含择时及固定定投持仓的总资产，使用各自起点 100 的相对口径；保留原始价格/金额读取能力。不显示 K 线、不改变现金流调整单位净值定义。
- VIX、回撤等辅助序列可按需折叠、单独绘制或叠加。所有可见图表继续共用时间窗口、定位、缩放、拖动和重置状态；保留坐标轴、单位、网格、图例和触屏行为。
- 结果详情用可访问的标签切换：策略比较、交易明细、完整指标；有网格搜索时显示搜索结果。比较表仍可访问所有现有绩效字段；窄屏横向滚动限制在表格内。
- CSV 始终从当前 `focusedResultId` 对应的不可变保存快照导出；草稿编辑不改变图表、表格、指标或 CSV 内容及字段。
- 全成功、部分失败、全部失败、不可用、运行中与无结果状态均清楚显示；失败诊断可定位到策略，不能遮盖其他成功策略。
- 右侧结果区作为独立的垂直滚动区，图表与结果详情都在其中滚动；不带动固定顶区、固定的共享设置/策略列表或策略详情滚动位置。

## 尺寸、滚动与可读性

| 视口 | 规则 |
| --- | --- |
| ≥1280px | 全宽双区工作台；固定顶栏及标题/ETF 信息；配置栏约 350px，可在 320–420px 调整；左侧共享设置/策略列表固定、当前详情区独立滚动；右侧结果独立滚动；取消 1180px 主内容上限。布局高度跟随实际视口，不能由固定最大高度或高视口最小高度制造额外页面留白。 |
| 768–1279px | 配置与结果以左右两栏正常流并排，配置栏可收起以扩展结果区；触屏和平板也不预留隐藏分隔列。展开时不覆盖内容，配置开关留在固定标题区。左栏内容较多时，策略导航在自身区域滚动。 |
| <768px | 使用“配置 / 结果”主视图切换；回测后可进入结果，且可随时切回配置。 |

桌面将滚动明确限制在策略详情和结果区；其余导航/上下文固定可见。图表默认普通滚轮滚动结果区；工具栏放置清楚可见的图标开关，可临时启用普通滚轮缩放；Ctrl/Command + 滚轮始终可缩放图表，所有图同步视窗。拖拽平移按指针在绘图区的实际位移映射，不应用小于 1 的灵敏度系数。加减按钮可直接缩放。调整栏宽、切换视图、打开/关闭对话框都应支持键盘，焦点清晰。延续当前中性底色、青绿色强调、日文默认与统一控件；主要可执行操作、选中模式使用清晰青绿色实底状态，次级按钮保持轻量。减少等权重嵌套卡片和重复说明。主要正文至少 14px，摘要、说明和次级交互文字至少 12px；图表轴标与高密度数据表可使用 10–11px。触屏命中区域至少 44px。颜色不能单独表达状态。

## 最终验收条件

1. 在 1440×900 滚动策略详情或结果后，顶栏/标题与 ETF 信息、左侧共通设置和策略列表均固定可见；当前策略详情和右侧结果各自独立滚动。首屏可辨识运行操作、四项核心指标、主图的实际绘图区和详情入口。
2. 1920px 页面全宽；1280/1024px 不挤坏图表与比较表；320/375/768px 不产生整页横向溢出、遮挡或裁切，表格横向溢出限制在表格内部。
3. 编辑对象、启停、运行范围、结果焦点、曲线显隐相互独立；旧快照、零结果、错误、运行中、部分失败、失败和数据不可用状态正确。
4. 图表相对值、原始值、价格与资产同图、辅图同步窗口/手势/重置、交易记录及四类 CSV 仍遵循已存结果快照口径。
5. 中/日文全流程 keyboard/ARIA 与 axe 检查合格；对应前端测试、typecheck、lint、build、E2E 通过，实际运行路径无 console/page 错误。
