# 设计指摘处理对照

本表只记录审查结论的唯一归属，不复制业务规则。计算与错误口径见[主设计稿](../superpowers/specs/2026-09-28-stock-etf-backtester-design.md)，预设、字段、模块、组件与顺序见[复用与组织规范](reuse-and-organization.md)，首屏状态见[画面源](backtest-ui.html)。最初十六项属于设计阶段记录；后续实现及用户覆盖规则以相关规范和任务记录为准。

| # | 指摘 | 设计处理与唯一归属 |
| --- | --- | --- |
| 1 | PE 缺失时 OR 继续跑，与策略不可用冲突 | 主设计稿「信号与统一缺失规则」：所有已启用必需信号严格三态，缺失使依赖策略不可用，其他策略继续 |
| 2 | 策略复权价与 PE 的每股价格基准混用 | 主设计稿「数据源与缺失处理」：`simulationPrice` 与 `valuationPrice` 分离，不可可靠区分则 PE 不可用 |
| 3 | 累计 YTD EPS 相减和非正 EPS 处理错误 | 主设计稿「个股 PE」及「ETF 持仓 PE 估算」：独立季度或年度口径；个股非正不可用，ETF 保留有效负盈利贡献 |
| 4 | 固定比例定投未并入总资产和排名 | 主设计稿「统一日历、账本与成交」：共用完整账本，固定部分计入所有结果与搜索 |
| 5 | 同日收盘信号/成交前视及交易撞单 | 主设计稿「统一日历、账本与成交」：次交易日成交、统一日内顺序、卖出与买入优先级 |
| 6 | VIX/复合、MA 两变体、基准、搜索算法复制 | 复用规范「策略目录与计算模块」：三种执行模块、两套预设变体、搜索包装及基准角色 |
| 7 | 三个运行入口和选中/启用/当前混淆 | 复用规范「草稿、作业与结果状态」「V1 组件清单」：一个范围分段控件、一个运行按钮、列表唯一启用开关 |
| 8 | 注资日及展示开关所属位置错误 | 复用规范「唯一参数注册表」：注资日归共享设置；图表/交易开关归结果展示偏好 |
| 9 | 策略目录缺 MA 只买和 VIX 重新添加 | 复用规范「策略目录与计算模块」与画面源：七类全列出，VIX 可删可再加 |
| 10 | 数字单位、边界、组件大小不一致 | 复用规范「唯一参数注册表」「V1 组件清单」：数值/单位拆分，注册表单源，统一输入尺寸 |
| 11 | 草稿与旧结果、聚焦 KPI、空结果混淆 | 复用规范「草稿、作业与结果状态」及画面源：冻结快照、独立结果焦点、首屏真实空态 |
| 12 | 31 日、休市、跨月和部分区间注资不定 | 主设计稿「统一日历、账本与成交」：一套含边界的有效注资日历供全部入口使用 |
| 13 | ETF 持仓覆盖率低于 100% 时公式偏差 | 主设计稿「ETF 持仓 PE 估算」：已覆盖成分重归一、门槛可调，保留负贡献 |
| 14 | 盈利率、投入倍数和网格并列排名不清 | 主设计稿「结果体验」：收益率与倍数分名，期末资产排序及稳定并列规则 |
| 15 | 语言控件、空态 CSV 和窄屏裁切 | 复用规范「V1 组件清单」及画面源：日文默认、真实语言按钮、无结果禁用 CSV；320/768/1024px 布局核对 |
| 16 | 模块、组件和实施先后缺组织归属 | 复用规范「模块接口与目录组织」「组织顺序与检查点」：接口/依赖、组件责任、五阶段验收 |
