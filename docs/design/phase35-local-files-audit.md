## 实现与验收范围

1. 默认 InMemoryRunStore，删除数据库实现/环境路径/数据库专用测试。真实供应商、会计、停止、幂等、候选与CSV断言保留，同进程查询正常，新进程无旧运行；未读取或删除个人旧运行文件。
2. `/runs/active` 只返回未完成作业；没有已完成结果自动恢复、IndexedDB写入或dismissed ID。重连只订阅一次SSE，结束只取一次完整响应。候选/结果仍保留进程内冻结身份。
3. 浏览器只在实际受理后保存配置、版本和时间；编辑和导入不保存，刷新恢复上次受理配置并清空已完成结果。
4. 策略文件取合法草稿，回测文件取冻结运行与所有候选详情；预览确认后原子替换。导入结果断开旧运行API后仍能显示候选、下载四类CSV/PNG、重新导出同一冻结结果。
5. 读取共享生成的OpenAPI JSON Schema，补充跨字段身份、状态和排名不变量；文件和API坏数据不进入组件。边界预算及格式的唯一维护点在复用规范，不在这里重复定义。

- 顶栏新增文件菜单造成320px品牌换行并遮挡sticky图表工具条；移动布局用省略方式保留可访问文本、固定头部高度，原布局断言保留。
- 科学计数转换必须只用于数值列，不能改写看起来像指数的股票代码、运行ID或信号ID；用字段契约区分，不靠字符串外观猜测。
