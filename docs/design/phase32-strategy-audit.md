- 通过保存 API 和三类相关 CSV 逐字段复核。十进制数值以 Decimal 比较，日期和身份精确比较；科学计数法和定点文本等价时不误判。网格搜索另独立复算阈值 20/25 的两项保存候选、交易、曲线和排名。

## 下载报告的产品行为与验收

- 结果详情的橙色「レポート.png / 报告.png」按钮下载当前明细策略或保存搜索候选。包含实际期间、投入计划、八项 KPI、完整价格/本金收益曲线及两项基准、回撤、保存买入上限/买卖条件、运行/数据/引擎指纹。
- 报告模型先抽取当前保存结果形成独立值，再等待字体并由本地原生 Canvas 编码；不读取草稿、图表缩放或显隐，不请求额外行情、不重新计算绩效。普通身份取当前运行的规范保存值；候选身份取其所属保存搜索。
- 日中翻译和主题共享现有 token；按实际字体测量 Unicode 换行，长条件/名称及指纹不截断。位图最多 1600 万像素、单边 16384，长报告降低像素倍率；编码后释放临时位图和下载 URL。
- 零交易但指标完整可以下载；运行中、候选读取中、失败或不可用时禁用。字体等待期间换焦点/重跑取消旧报告；编码失败可见且可重试，不静默生成空图。
- 四项浏览器测试检查原生 PNG 签名/尺寸、实际写入文字/保存数值、两种语言及 320px axe、草稿 100 改成 999 后旧报告仍为 100、零交易、故障重试、取消和保存搜索候选。
- 另将 11 类真实成功保存响应交给产品下载入口生成 PNG，全部签名/像素预算与指标一致。已查看真实 VIX 报告及工作台截图，文字/曲线/配置可读，无裁切；PE 按设计禁用。测试图片与运行库留在忽略目录 `.local/verification/phase32/reports/`，不加入 Git。
