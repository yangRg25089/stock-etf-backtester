## 保留的已确认修正

- 参考脚本同日形成并成交信号。本项目收盘信号在下一交易日成交，最后日信号记录为未执行。
- 参考脚本缺失宏观值前向填充，AND 跳过 NaN。本项目各启用叶节点输出 true/false/unavailable；OR/AND 均不绕过必需缺失。
- 参考脚本 `cash == 0` 提前跳过后续卖出。本项目现金为零仍评估持仓卖出；卖出执行日抑制择时买入和安全阀。
- 参考脚本部分 `strategy_value` 未包含固定定投仓位。本项目总资产统一包括现金、择时和固定定投仓位；固定比例 100% 与同注资日历 DCA 等价。
- RSI 使用已确认 Wilder 平滑；布林使用已确认的标准差规则，不另复制 pandas rolling 口径。
- `totalContributed` 是注资本金，包含尚未买入的现金；实际成交买入额作为独立指标处理，收益/XIRR 分母不改写。
