| 发现 | 页面及源码证据 | 影响 |

外层溢出的主要修复假设已由源码和几何证据定位：`.sr-only` 使用 absolute，结果区到根节点之间没有定位包含块，隐藏的详情标题及表格 caption 越过结果滚动区。1920×1080 下 caption 底边约 2780.43px，与 document 高度吻合。在页面外缘滚动 900px 后，结果区自身 `scrollTop` 仍为 0，应用底边移到约 181px，出现大面积空白。另有顶栏实际 61px、工作区按 60px 扣除导致的 1px 超高。Task 47 必须修复定位/裁切与高度分配并验证，不能只隐藏外层滚动条。

本轮使用恢复的已保存结果，没有新建回测；草稿为 QQQ、保存图表为 SMH。这说明右侧需要简短明确的保存标的/期间，避免把当前草稿摘要误认为结果来源。上述尺寸是浏览器 CSS 视口，不等同于真实浏览器缩放验证。

## 页面结构

```text
┌─────────────────────────────────────────────────────────────────────┐
│ [侧栏] 产品名称                          [▶ 全部 3 ▾] [日本語 / 中文] │
├──────────────────┬──────────────────────────────────────────────────┤
│ 共通设置摘要  ⚙  │ ▾ 结果详情 [保存标的 · 期间] [结果策略 ▾] [导出]   │
│ 整块点击开 dialog│   概览 / 比较 / 交易 / 搜索（适用时）              │
│                  │   本金、期末资产、收益率、XIRR、最大回撤           │
│ [策略选择 ▾] [+] ├──────────────────────────────────────────────────┤
│                  │ [图例] [叠加布局] [时间轴联动] [缩放模式 − + ↺]   │
│ 策略摘要卡 1     │ ↑ 阅读图表时此行 sticky                           │
│ 策略摘要卡 2     │ ▾ 价格 / 总资产 · 起点 100                         │
│ …                │   主走势图                                       │
│ 点击卡片开 dialog│ ▸ 回撤                                            │
│ 列表独立滚动     │ ▸ VIX                                             │
└──────────────────┴──────────────────────────────────────────────────┘
```

只保留一个常驻应用顶栏，目标高 52–56px；主区域通过剩余网格行占满有效视口。左栏默认约 300px、可在 260–360px 调宽；右侧占满剩余空间。侧栏开关位于顶栏左侧固定位置，展开和关闭使用同一按钮。桌面外层不承担结果内容的纵向滚动。

### 顶栏与执行

删除可见 `.page-heading` 和独立 `.run-controls` 条，产品名称承担页面识别。顶栏右侧使用唯一醒目的播放主按钮，旁边紧凑显示范围，如“全部 3 ▾”或“当前 1 ▾”。范围菜单保留明确文字与选中状态，默认全部启用策略。运行中在该位置显示忙碌/进度并禁用重复提交；不可执行原因有可访问说明；正常完成只做一次短暂反馈和辅助技术播报。

编辑对象、启停、运行范围、结果焦点、图例继续相互独立；点击播放不能通过隐式改变其他状态来凑出可运行配置。

### 共通设置 dialog

共通设置摘要整体采用一个原生 button，显示简短标的、期间、投入计划和装饰性齿轮；任意位置及 Enter/Space 均可打开 dialog，不嵌套按钮。

dialog 目标宽约 840px，纵向分为标的、期间、投入计划三段；期间为开始/结束两列，投入为金额/每月日期两列，每段最多两列。组间 24px、字段间 16px；结束日模式和日期归在同一字段区，输入对齐，说明位于字段下方。320px 下单列，标题、关闭和完成操作常驻，表单内容独立滚动。复用 catalog、现有共享表单及校验，编辑即时更新草稿，关闭重开保留值并返回触发控件。

### 策略 dialog 与左栏

策略区域第一行是目录选择器和添加图标，第二部分是已添加摘要卡列表。取消 55%/45% 高度分配和下方内嵌编辑器。卡片按内容高度排列，包含名称、关键参数、启停及校验状态；缩略图采用信息摘要卡，不绘制无数据的模拟收益线。

卡片主体是打开策略 dialog 的按钮，启用及删除/更多操作为同级控件，不能冒泡开窗。dialog 目标宽约 960px、最高约 85dvh；按 catalog 参数组显示一至两列字段，长策略提供组导航和内部滚动。七类预设及搜索参数复用注册表，共通字段不复制进策略 dialog。关闭/完成/Escape 保留草稿并返回焦点；删除实例后焦点回到相邻卡片或添加入口。校验入口能开窗并定位错误字段。

### 结果详情与状态

- `.result-details` 成为右侧首卡，取消独立聚焦 KPI 卡和“查看详情”跳转。标题行显示保存标的/日期、正在查看的结果策略选择器和导出操作。
- 默认概览页包含五项核心指标，使用同一条指标区和轻量分隔，减少五个套框。其余指标在概览内展开，核心指标不重复。其他页为比较、交易及适用时的搜索。
- 结果选择器和比较表均可切换保存结果，独立于左侧编辑。新运行恢复/完成后显示该次结果默认概览，不沿用不适用的搜索页。导出作为标题行菜单，提供既有四类 CSV，零交易仍可导出表头。
- 删除正常完成的 `.run-status-panel.is-compact`、常驻原始 run ID 和重复成功标签。运行中、请求错误、局部失败、failed/unavailable 在结果标题上下文显示简短状态与可展开诊断，受影响策略及原因可查，成功结果仍可查看。
- 草稿不同于快照时显示简短“旧输入”标记及详情；保存标的/日期始终可读。ID、来源、覆盖等技术信息放入“更多/来源”详情。

### 右侧折叠与图表

右侧模块统一使用折叠标题行：左侧 chevron 和名称，右侧相关操作。结果详情和价格/总资产主图默认展开；回撤及 VIX 默认折叠且保留辨识信息。折叠只改变界面，不重置结果、图例或日期窗口；异常原因在折叠标题附近仍有入口。每个模块只保留一层主要边界。

所有图共享工具栏，进入图表区域后在右侧滚动容器顶部 sticky，直到离开图表区域。联动图标及提示明确所有图共用日期窗口。滚到第三图时缩放模式、减/加、重置、叠加布局仍可达；工具栏不遮挡标题或焦点。此方案优先于重复三套同义操作。

保留价格与总资产同图、起点 100、现金流调整单位净值及原始值提示；VIX/回撤可分图或叠加，各日期轴继续同步。普通滚轮默认滚动结果区，显式模式或 Ctrl/Command+滚轮缩放；拖动跟随指针，不重新加入半速系数。

1920×1080 下主图绘图区目标高 320–420px，辅助图 180–240px，短视口相应收紧；不能仅按宽度无限增高。改变尺寸时重新验证指针到实际 SVG 绘图区的映射，防止缩放锚点及拖动失准。坐标轴、网格、单位、交易点和细线辨识保留。

### 额外扁平化规则

- 去掉“设置/共通设置”“结果/结果详情”及页签/内部表格标题的重复可见标题。辅助技术标题/caption 保留，并正确限制在对应模块内。
- 运行、添加、编辑、关闭、删除、导出、折叠、缩放、布局等通用动作采用一致图标，具有双语 accessible name、焦点和悬停/触屏可达提示。策略名、指标名、字段 label 和错误原因保留文字。
- 比较表默认去掉每行内部 ID，以名称和紧凑角色标记辨识策略/基准。长名称换行，横向滚动限于表格本身；全部绩效字段和原始数值仍可访问。
- 固定长解释改为简短说明或信息 popover；复杂字段的含义、单位、依赖及错误不能用纯图标代替。校验问题归属到设置或具体策略，不常驻重复的大卡片。
- 延续中性底色与青绿色强调；播放为实底主操作，次级工具轻量，选中/禁用/焦点可区分。模块间距 12–16px，字段标签及说明统一字号，正文 14px、次级 12px，减少内层套卡。

## 最终验收

1. 检查 1920×1080、1920×947、1536×864、1366×768、1280×720 及 320/375/768/1024/1440px 中日文；另检查真实浏览器 100%/125%/150% 缩放。桌面 document 不因隐藏元素或结果内容溢出有效视口，外缘滚动不露出空白；列表、结果和 dialog 内容各在所属区域滚动。
2. 1920×1080 默认首屏可辨识共通设置入口、策略目录/卡片、播放/范围、五项 KPI 和主图至少 280px 的实际绘图区；1440×900 至少 220px。测量实际绘图区可见范围，不能只测 SVG 外框。
3. 共通设置整块可点；策略卡片开 dialog，启停/删除独立；键盘、字段错误定位、关闭重开及焦点返回正确。编辑对象、启用、范围、结果焦点、图例和快照的独立语义有回归证据。
4. 首卡为合并结果详情，正常成功卡和重复核心 KPI 区不出现；empty、运行中、请求失败、局部失败、unavailable、零交易和旧输入均可读；四类 CSV 从同一保存快照导出。
5. 第三图工具仍可达，折叠后日期窗口/图例保留；分图/叠加、普通滚动、两种缩放模式、键盘、拖动和重置正确且跨图同步。
6. 双语 keyboard/ARIA/axe 合格，触屏命中区至少 44px，长名称及说明不裁切；实际前端测试、typecheck、lint、build、E2E 通过，真实 QQQ/VIX 运行及恢复复核通过，原型/设计/计划/进度一致。

实现阶段每个 Task 按 loop-engineering 进行实现、验证、审查、修复、简化和再验证，满足条件后关闭，检查点不跳过。全部交付后按用户既有要求运行 stabilization-loop，以可复现问题进入修复循环，不无限扩大产品范围。
