## 页面结构

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 产品名称                              [▶] [↺] [日本語 / 中文] │
├──────────────────┬──────────────────────────────────────────────────┤
│ 共通设置摘要   < │ ▾ 结果详情 [ⓘ 保存来源] [↓ 汇总.csv 等]   │
│ 整块点击开 dialog│   策略比较 / 交易 / 搜索（适用时）              │
│                  │   本金、期末资产、收益率、XIRR、最大回撤           │
│ [策略选择 ▾] [+] ├──────────────────────────────────────────────────┤
│                  │ [图例] [分图 / 联动] [缩放模式 − + ↺]   │
│ 策略摘要卡 1     │ ↑ 阅读图表时此行 sticky                           │
│ 策略摘要卡 2     │ ▾ 价格 / 累计本金收益                         │
│ …                │   主走势图                                       │
│ 点击卡片开 dialog│   回撤 (%) · 小型联动指标                                            │
│ 列表独立滚动     │   VIX · 小型联动指标                                             │
└──────────────────┴──────────────────────────────────────────────────┘
```

只保留一个常驻应用顶栏，目标高 52–56px；主区域通过剩余网格行占满有效视口。左栏使用固定宽度、右侧占满剩余空间。取消拖动调宽，侧栏开关位于左右栏的边界线上，使用无边框 `< / >`。关闭后保留边界入口，重开恢复原位置；窄屏使用设置/结果切换。桌面外层不承担结果内容的纵向滚动。

### 顶栏与执行

删除可见 `.page-heading` 和独立 `.run-controls` 条，产品名称承担页面识别。顶栏右侧使用唯一醒目的播放主按钮，只运行全部启用策略并自动附带月度定投和一次投入基准；移除范围菜单，后端仍兼容 active/all_enabled。运行中在该位置显示忙碌/进度并禁用重复提交；不可执行原因有可访问说明；正常完成只做一次短暂反馈和辅助技术播报。播放旁增加重置图标，仅清空当前显示结果/错误；运行中禁用，不删除 SQLite 记录。客户端记住清空的 runId，刷新不再恢复同一结果；新提交结果可以正常恢复。删除本机运行文字标签。

编辑对象、启停、结果焦点、图例继续相互独立；点击播放不能通过隐式改变其他状态来凑出可运行配置。

### 共通设置 dialog

共通设置摘要整体采用一个原生 button，股票代码、具体日期期间、带单位的投入计划各占一行，不显示齿轮；任意位置及 Enter/Space 均可打开 dialog，不嵌套按钮。

dialog 目标宽约 840px，纵向分为标的、期间、投入计划三段；期间为开始/结束两列，投入为金额/每月日期两列，每段最多两列。组间 24px、字段间 16px；结束日模式和日期归在同一字段区，输入对齐，说明位于字段下方。320px 下单列，标题、关闭和完成操作常驻，表单内容独立滚动。复用 catalog、现有共享表单及校验，编辑即时更新草稿，关闭重开保留值并返回触发控件。说明缩短；金额字段显示匹配保存标的的确认币种，否则显示交易货币单位，不推测币种。草稿校验只在设置侧/字段显示，不改变右侧保存结果或运行错误。

### 策略 dialog 与左栏

策略区域第一行是目录选择器和添加图标，第二部分是已添加摘要卡列表。取消 55%/45% 高度分配和下方内嵌编辑器。卡片按内容高度排列，包含名称、关键参数、启停及校验状态；缩略图采用信息摘要卡，不绘制无数据的模拟收益线。

卡片主体是打开策略 dialog 的按钮，启用及删除/更多操作为同级控件，不能冒泡开窗。删除卡片运行目标按钮。启停 switch 和删除仅在真实 hover 或键盘 :focus-visible 时浮于右上，触屏常驻；停用卡灰色且保留可编辑性。dialog 目标宽约 960px、最高约 85dvh；按 catalog 参数组显示一至两列字段，长策略内部滚动。每组只显示一个标题，买入组合只提供 AND/OR 分段选择，并用已启用买入信号卡片与连接词显示关系，解释放在短提示/可访问名称；不重复导航或参数摘要。布尔信号用 switch 与简短状态，买入与卖出独立。鼠标关闭 dialog 后返回焦点不留下操作浮层，键盘返回仍可访问操作。五种可添加预设及搜索参数复用注册表，每类最多一个，已添加选项禁用并由 reducer 二次防重，删除后可重加；月度 DCA 和一次投入作为必选自动基准，不出现在添加菜单，后端目录仍保留七类，共通字段不复制进策略 dialog。关闭/完成/Escape 保留草稿并返回焦点；删除实例后焦点回到相邻卡片或添加入口。校验入口能开窗并定位错误字段。

### 结果详情与状态

- `.result-details` 是右侧首卡；标的和日期集中在共通设置，摘要使用同标的保存行情的实际截至日，尚未确认时显示占位。右侧保存标的/日期/策略身份从信息图标按需查看，不重复常驻。标题提供四类下载入口（下载图标和 `.csv` 文件型名称），删除 result-focus-select。
- 默认策略比较页包含全部八项绩效指标，移除概览/其他指标重复页；点击比较行切换图表、交易与 CSV 焦点，自动基准保留角色，历史 API 同类实例仍以短序号区分。其余页为交易和适用时的搜索。
- 交易表限定最大高度，独立滚动且表头 sticky；长表横向溢出仅限表格容器。
- 正常完成不显示独立状态卡/原始 run ID。运行中、请求错误、局部失败及不可用保留简短状态与诊断，成功结果仍可查看。
- 右侧只读取不可变 RunSnapshot：草稿编辑、停用、切换或删除不生成旧输入提醒、不清除运行错误、不把配置校验挂进右侧。保存标的/期间及策略身份可按需查看，来自结果快照。只有执行、恢复、重置改变当前结果；结果聚焦、页签与图表交互只改变显示。

### 右侧折叠与图表

右侧模块统一使用折叠标题行：左侧 chevron 和名称，右侧相关操作。结果详情和价格/累计本金收益主图默认展开；分图模式回撤及 VIX 默认折叠，联动模式在主图下方显示选中的紧凑指标。折叠只改变界面，不重置结果、图例或日期窗口；异常原因在折叠标题附近仍有入口。每个模块只保留一层主要边界。

所有图共享工具栏，进入图表区域后在右侧滚动容器顶部 sticky，直到离开图表区域。联动图标及提示明确所有图共用日期窗口。滚到第三图时缩放模式、减/加、重置、分图/联动布局仍可达；工具栏不遮挡标题或焦点。此方案优先于重复三套同义操作。

价格与资产收益始终同图：价格除以首个有效价格乘 100；资产收益为总资产除以当日累计投入本金乘 100，不再次按首个收益值归一。累计本金由后端共享现金流模块逐日记录，前端不复制注资日历；零本金不画收益点，旧快照缺字段提示重新运行；只隐藏价格线时保留资产主图，至少保留一条可用核心曲线及恢复入口。原始金额保留在提示和保存 CSV，单位净值/最大回撤/XIRR 继续原有算法。联动模式将 VIX/回撤以自然单位放在主图下方的较小指标图，与主图同宽、网格对齐；不新增 RSI。普通滚轮默认滚动结果区，显式模式可反复开启/关闭，Ctrl/Command+滚轮仍缩放；拖动跟随指针，SVG 禁止文字选择。

分图模式主图、回撤和 VIX 使用相同完整图高；联动模式主图完整、辅助图较小。1920×1080 主图绘图区目标高 320–420px，短视口统一收紧；不能仅按宽度无限增高。改变尺寸时重新验证指针到实际 SVG 绘图区的映射，防止缩放锚点及拖动失准。主图纵轴 8 个刻度、横轴最多 7 个日期；窄屏可隐藏隔行日期文字但保留网格。坐标轴、单位、交易点和细线辨识保留。默认细线约 1.2px；悬停或键盘聚焦图内图例时，对应线加粗并绘制同色透明渐变面积，离开后恢复，不改变全局曲线显隐和日期窗口。

指针悬停时使用最近保存日的跨图纵线和当前图横线，左上显示该日原始价格、总资产、累计本金、相对指数及自然单位指标；缺值显示占位，不插值、不虚构 OHLC。Shift+左右键逐日查看，Escape/离开收起；拖动与缩放清除旧定位。读数作为图内覆盖层，不挤占原绘图区。

### 额外扁平化规则

- 去掉“设置/共通设置”“结果/结果详情”及页签/内部表格标题的重复可见标题。辅助技术标题/caption 保留，并正确限制在对应模块内。
- 运行、添加、编辑、关闭、删除、导出、折叠、缩放、布局等通用动作采用一致图标，具有双语 accessible name、焦点和悬停/触屏可达提示。策略名、指标名、字段 label 和错误原因保留文字。
- 比较表默认去掉每行内部 ID，以名称和紧凑角色标记辨识策略/基准。长名称换行，横向滚动限于表格本身；全部绩效字段和原始数值仍可访问。
- 固定长解释改为简短说明或信息 popover；复杂字段的含义、单位、依赖及错误不能用纯图标代替。校验问题归属到设置或具体策略，不常驻重复的大卡片。
- 延续中性底色与青绿色强调；播放为实底主操作，次级工具轻量，选中/禁用/焦点可区分。模块间距 12–16px，字段标签及说明统一字号，正文 14px、次级 12px，减少内层套卡。

## 最终验收

1. 检查 1920×1080、1920×947、1536×864、1366×768、1280×720 及 320/375/768/1024/1440px 中日文；另检查真实浏览器 100%/125%/150% 缩放。桌面 document 不因隐藏元素或结果内容溢出有效视口，外缘滚动不露出空白；列表、结果和 dialog 内容各在所属区域滚动。
2. 1920×1080 默认首屏可辨识共通设置入口、策略目录/卡片、播放/重置、完整策略比较和主图至少 280px 的实际绘图区；1440×900 至少 220px。测量实际绘图区可见范围，不能只测 SVG 外框。
3. 共通设置整块可点；策略卡片开 dialog，启停/删除独立；键盘、字段错误定位、关闭重开及焦点返回正确。编辑对象、启用、结果焦点、图例和快照的独立语义有回归证据。
4. 首卡为合并结果详情，正常成功卡和重复 KPI 区不出现；empty、运行中、请求失败、局部失败、unavailable 和零交易均可读；草稿编辑不改变右侧 DOM，重置/刷新与重跑正确；四类 CSV 从同一保存快照导出。
5. 第三图工具仍可达，折叠后日期窗口/图例保留；分图/联动、普通滚动、两种缩放模式、键盘、拖动和重置正确且跨图同步。
6. 双语 keyboard/ARIA/axe 合格，触屏命中区至少 44px，长名称及说明不裁切；实际前端测试、typecheck、lint、build、E2E 通过，真实 QQQ/VIX 运行及恢复复核通过，原型/设计/计划/进度一致。

实现阶段每个 Task 按 loop-engineering 进行实现、验证、审查、修复、简化和再验证，满足条件后关闭，检查点不跳过。全部交付后按用户既有要求运行 stabilization-loop，以可复现问题进入修复循环，不无限扩大产品范围。
